# Next.js Dynamic Routing Playground

This repo contains mini-projects exploring various dynamic routing patterns in Next.js.

## Projects

### 1. `project-basic-dynamic-routing`

Simple `[slug].js` route example.

### 2. `project-nested-dynamic-routing`

Nested routes using `[user]/[post].js`.

### 3. `project-catch-all-routing`

Catch-all routes using `[...slug].js`.

## How to Use

Each project is a standalone Next.js app. `cd` into a folder, then run:

```bash
npm install
npm run dev
